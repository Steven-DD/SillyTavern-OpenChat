> **方法**：代码级盘点（非运行时截图比对）。逐功能域核对 App 实际代码（views / stores / services/st/*、src-tauri/src），对照 ST 网页端 public/scripts 实际能力；标注 ✅对齐 / ◑部分对齐 / ❌未对齐，结论均附代码位置。
> **版本说明**：本版取代同日早间的《能力对齐盘点_2026-09-25.md》。相对上一版的核心变化：**4.1 世界书注入、4.2 消息编辑/删除/重发、4.3 Markdown 渲染、4.4 Swipe、4.6 推理内容展示均已在代码中落地**，消息分支/书签为本次盘点新发现。

## 六、建议的补齐顺序

1. **停止生成 abort**（P1）—— `stStream` 加 AbortController + 按钮态切换，半天级工作量，是当前唯一的"基础体验残缺"
2. **作者注释独立模块**（P1）—— 顺带替换 3.7 的近似注入，为记忆三件套铺路
3. **记忆三件套**（P1）—— vectors/summarize 走 ST 现成后端端点
4. **会话全文搜索 + 宏高频五个 + tokenizer 接入**（P2/P3 打包）—— 三个"接口级"小项，一次性消掉三格 ◑
5. **Prompt Manager 简化版**（P2）—— main/jailbreak/NSFW 三槽先行
6. 群聊、Text Completion、标签系统按 v1.1 排期

> 注：本版为代码级盘点。世界书递归扫描/timedEffects 与 ST 默认行为一致（均关闭），故未列为缺口；若需运行时逐项点验（App 与 ST 网页端同卡同会话并排对比生成效果），可另起一轮 E2E。
