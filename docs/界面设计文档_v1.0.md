## 一、全局一致性规则（硬约束，阶段三前端布局开发必须遵守）

> 用户定调：所有页面共用**同一个布局壳**，不得出现破坏三栏骨架的独立页面。

| 区域 | 职责 | 内容路由 |
|------|------|----------|
| **左栏**（全局导航） | 四个入口**全局固定不变**（同微信） | 会话 / 联系人 / 插件 / 设置 |
| **中栏**（二级列表栏） | 列表内容随左栏入口切换 | 会话→会话列表；联系→角色卡列表；插件→插件列表；设置→设置分类列表 |
| **右栏**（统一内容区） | 一级内容 + 二级面板，承载一切主内容 | 聊天流 / 角色卡编辑 / 插件详情 / 设置表单 |

- 前端实现思路：**一个布局壳 + 中栏内容切换 + 右栏内容路由**
- 反例（已废弃）：设置页、插件页做成带自己子导航的独立整页

## 二、整体布局骨架（冻结版）

![01 整体布局](界面图/01_整体布局.svg)

**三栏结构：**

1. **左栏 · 全局导航**：会话 / 联系人（角色卡）/ 插件扩展 / 设置，四入口固定
2. **中栏 · 会话列表**：列表项 = ST 会话（角色 + 世界书等配置驱动），显示会话名与配置摘要
   - 切到"联系人"入口 → 中栏显示角色卡列表
3. **右栏 · 聊天区**：
   - 顶栏：当前会话名 + 配置入口
   - 消息流：AI 气泡（左）/ 用户气泡（右），支持流式回复
   - **状态条（输入框上方）**：连接状态 · 模型名 · 上下文 token 用量 · 本轮 token 用量
   - 输入框 + 发送按钮

**状态条规则**：与设置页"连接测试"联动——测试结果、连接异常均实时反映在此处。

## 三、右侧两级内容区交互方案

![02 两级内容区交互](界面图/02_两级内容区交互.svg)

用户洞察（已采纳）：微信右侧实际是"**一级内容区（聊天流）+ 二级内容区（配置面板）**"两级结构。

| 项 | 规则 |
|----|------|
| 唤起 | 点击聊天顶栏「···」按钮 |
| 关闭 | 面板「×」或再点「···」 |
| 呈现方式 | **推挤式**（同微信 PC）：聊天流 / 状态条 / 输入框同步收窄 |
| 关键约束 | 二级面板展开/收起**不得中断流式回复** |
| 改动生效 | 面板内改动即时生效当前会话（走 ST API） |
| 深度编辑 | 世界书条目等复杂编辑 → 跳转中栏对应列表页处理 |

## 四、会话配置面板（二级面板详细设计）

![03 会话配置面板](界面图/03_会话配置面板.svg)

四个 Tab：

1. **信息**：会话名称 / 角色（头像 + 更换）/ 背景（点击选择）
2. **世界书**：已挂载勾选启用（未挂载灰显）/「+ 挂载新世界书」/ 拖拽调整注入顺序
3. **预设与参数**：预设下拉 / 温度滑杆 / top_p 滑杆 / 最大回复 tokens
4. **记忆**（三件套）：
   - 总结记忆（Summarize）：开关 + 查看摘要
   - 向量存储（Vector Storage）：开关
   - 作者注释（Author's Note）：多行文本 + 注入深度

**归属边界**：预设库管理、Persona、API 配置归**设置页**，不塞进会话面板。

## 五、角色卡管理页（联系人）

![04 角色卡管理页](界面图/04_角色卡管理页.svg)

**中栏 · 联系人视图**：
- 顶部：搜索框 + [+ 新建] + [导入]
- 卡片：头像 / 名称 / 描述摘要 / 关联会话数
- 交互：单击卡片 → 右栏打开详情

**右栏 · 详情/编辑页**：
- 顶栏：返回 / 导出 PNG
- 头部：大头像 + 名称 + tags
- 基本信息组：描述 / 性格 / 场景
- 对话组：首条消息 / 备选问候
- 底部：保存 / 删除（二次确认）/ 高级字段（折叠）

**导入导出**：支持 ST 标准 PNG 角色卡（内嵌数据）与 JSON；导出 PNG 与 ST 生态互通。

## 六、设置页（三栏模式呈现）

![05 设置与插件页 · 修正版](界面图/05_设置与插件页_修正版.svg)

- 中栏 = 设置分类列表：**API 与模型 / Persona / 界面偏好 / 数据**
- 右栏 = 分类对应表单。以「API 与模型」为例：
  - API 类型下拉 / API 地址 / API 密钥 / 模型下拉
  - 「连接测试」按钮 + 连接状态显示（已连接 · 延迟）
- **安全规则**：API Key 仅存本地，不上传
- **联动**：连接测试结果同步至聊天区状态条

## 七、插件扩展页（三栏模式呈现）

- 中栏 = 插件列表：名称 / 版本 / 来源 / 启用状态点 /（停用项灰显）+ [+ 安装扩展]
- 右栏 = 插件详情/管理：启用开关 / 插件设置项 / 说明 / 保存
- 首版插件范围：ST 现有扩展接入 —— 总结记忆 / 向量存储 / 作者注释 / 表情等

**插件体系路线（阶段一已决策）**：
1. 首版：**最小可接入插件**（最小代价接入 ST 现有扩展）
2. 演进：有问题再自建插件体系（"万物可插件"，参考 DeepSeek harness 思路）
3. 开源后：皮肤 / 主题为首批开放扩展点

## 八、设计规格约定

- 线框图统一规格：viewBox 680 宽、0.5px 描边、浅色填充 + 深色文字、无渐变阴影
- 线框配色（蓝 #E6F1FB/#185FA5、紫 #EEEDFE/#534AB7、teal #E1F5EE/#0F6E56、amber #FAEEDA/#854F0B、灰 #F1EFE8/#5F5E5A）仅为线框区分用，**非最终视觉稿**；正式主题（含深色模式）在阶段三 UI 实现时另行设计
- 字号 ≥ 10px，所有文本垂直居中（dominant-baseline: central）
