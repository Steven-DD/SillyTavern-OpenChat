# B6 批次方案：收尾（2026-09-28）

> 目标：消化剩余可落地项 —— M-19 auto-continue / M-20 消息隐藏+旁白 / M-15 Horde / M-18 data-maid UI /
> M-10 表情立绘最小版。纯 UI 大件（M-11 文生图体系、M-17 i18n）与不适用项（M-16）诚实收口记账。

## ST 事实（源码实测）

- **auto-continue**（script.js:5717-5769）：`power_user.auto_continue = {enabled, target_length,
  allow_chat_completions}`；回复结束后消息 token 数 < target_length → 用 continue 管线续写
  （App 侧允许 CC：与 ST 的 allow_chat_completions=true 等价）
- **is_system**：消息隐藏开关（script.js:1851 usableMessages 过滤）——`is_system: true` 的消息
  **不进 prompt**，UI 仍显示（系统消息样式）；/sys 命令产生此类消息（旁白）
- **Horde**（horde.js）：`POST /api/horde/generate-text`（body 透传 aihorde async API）→ `{id}`；
  `POST /api/horde/task-status {taskId}` → `{done, faulted, generations:[{text}], wait_time,
  queue_position}`；`POST /api/horde/cancel-task {taskId}`；模型列表 `/text-models`
- **data-maid**：`POST /api/data-maid/report` → `{report: {images, files, chats, groupChats,
  avatarThumbnails, backgroundThumbnails, personaThumbnails, chatBackups, settingsBackups}, token}`；
  `POST /api/data-maid/finalize {token}` → 204（按 token 清理）
- **sprites/classify**：`GET /api/sprites/get?name=<char>` → `[{label, path:'/characters/...'}]`；
  `POST /api/extra/classify {text}` → topk `[{label, score}]`（extra 模块启用时才可用，需容错）

## 子任务

### 6.1 auto-continue（M-19 主体）
- settings 读 `power_user.auto_continue`（enabled/target_length）
- `generateReply` 成功后：`estimateTokens(reply) < target` → 用 continue 管线追加续写，
  最多 3 轮防死循环；中断即停
- 设置页「模型」或插件卡加开关 + 目标长度（透传 ST 字段，可读写回写 power_user）

### 6.2 消息隐藏 + 旁白（M-20）
- chatdoc：DisplayMessage 映射 `isSystem`（m.is_system）；toStMessages 保留
- prompt 组装：is_system 行不进 history（对齐 usableMessages 过滤）
- 气泡工具条加「隐藏/显示」（行级落盘；隐藏气泡半透明 + 已隐藏徽标）
- stscript 加 `/sys 文本`：插入旁白（is_system 消息）

### 6.3 Horde 源（M-15 完）
- api.ts source 'horde'：generate-text 提交 → task-status 每 3s 轮询（300s 超时）→
  generations[0].text 一次性回调；AbortSignal 触发 cancel-task
- CHAT_SOURCES 加 Horde；fetchModels 支持 /api/horde/text-models

### 6.4 data-maid 报告 UI（M-18 完）
- services/st/datamaid.ts：runReport()/finalize(token)
- 设置页「数据巡检」卡片：按钮生成报告 → 分组计数展示 → 确认后 finalize 清理

### 6.5 表情立绘最小版（M-10 ◑）
- services/st/expressions.ts：listSprites/classifyText（容错）
- chat store：回复完成后 classify 最新回复 → currentEmotion；ChatPanel 显示当前表情
  + 立绘预览 + 手动选表情；classify 不可用（extra 未启用）时 UI 降级为手动

### 6.6 验收
- 离线自检：is_system 过滤 + /sys 命令 + auto-continue 触发条件纯函数断言
- 回写盘点/路线图/记忆；M-11/M-16/M-17/M-21/M-22 记账收口

## 明确不做（范围外）
- M-11 文生图 SD/图库/附件体系（独立扩展群，App 形态价值有限）
- M-21 采样器高级 UI 扩展（现有 sampler 字段已覆盖主流；cfg/logprobs 低使用率）
- M-22 请求压缩/抓取器
- M-17 i18n（全量多语言包工程，单列）
