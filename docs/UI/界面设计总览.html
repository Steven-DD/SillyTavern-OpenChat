◎ 全局一致性规则（阶段三前端布局硬约束）

三栏布局全局统一：左栏四入口（会话 / 联系人 / 插件 / 设置）固定不动，与微信一致；中栏为二级列表栏，右栏为统一内容区。中栏与右栏的内容随左栏入口路由切换——任何页面（含设置、插件）都不得脱离这个布局壳使用独立页面。

1

整体布局（v2 冻结版）

应用全局骨架：左栏全局导航四入口、中栏会话列表、右栏聊天区。状态条位于输入框上方，显示连接状态 / 模型名 / token 用量，与设置页连接测试联动。
2

右侧两级内容区交互

右栏分一级聊天区与二级配置面板。点顶栏「···」唤起配置面板，推挤式呈现（同微信 PC），聊天流 / 状态条 / 输入框同步收窄，流式回复不中断。面板含四 Tab：信息 / 世界书 / 预设与参数 / 记忆。
3

会话配置面板 · 四 Tab

二级面板内四个 Tab 的表单内容。所有改动即时保存并生效于当前会话（走 ST API）；世界书条目深度编辑跳转中栏列表页，预设库 / Persona / API 配置归入左栏「设置」。
4

角色卡管理页（联系人）

联系人 = 角色卡。中栏为联系人列表（搜索 / 新建 / 导入），右栏为角色卡详情编辑。导入支持 ST 标准 PNG 角色卡（内嵌数据）与 JSON，与 ST 生态双向互通。
5

设置页与插件页（一致性修正版）

修正后的设置与插件模式：左栏四入口固定，中栏为二级列表（设置分类 / 插件列表），右栏为表单或详情。两个模式共用同一个布局壳，通过路由切换内容。
