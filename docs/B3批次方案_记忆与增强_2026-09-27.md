# B3 批次方案：记忆与增强（M-6 / M-7 / M-12）（2026-09-27）

## 1. M-6 Summarize 总结记忆

**ST 事实**：memory 扩展纯前端编排；摘要存 **chat_metadata.summary**；设置在 `extension_settings.memory`
（prompt/template/interval/depth/role/position）；注入走扩展提示词（深度/角色可配）。

**实现**：
- 服务 `services/st/memory.ts`：
  - 设置读写：`extension_settings.memory`（ST 同键）：`{prompt, template, interval, depth, role, position}`，
    App 开关存 `extension_settings.stchat_memory.enabled`
  - 摘要读写：`chat_metadata.summary`（与 ST 完全互通）
  - `generateSummary(...)`：用主生成通道（generate/generateText）以 ST 风格总结提示词
    （默认模板含 {{words}} 限 200 词）对「上一版摘要 + 近期历史」生成新摘要 → 写回 chat_metadata
- 注入：`buildPrompt` 新增 `memory?: {content, position, depth, role}` —— position=0 系统提示顶部 /
  1 @Depth（默认 depth 2 system，贴近 ST 常用）
- UI：ChatPanel「记忆」Tab 增加分区：当前摘要展示 + 「更新摘要」按钮 + interval 说明；
  设置（interval/depth/role/模板）在 设置 → 通用 的插件功能卡片
- 自动触发：send 完成后 `messages.length % interval === 0` 时静默更新（失败不打断）

## 2. M-7 Vectors 向量检索

**ST 事实**（src/endpoints/vectors.js 实测）：
- `POST /api/vector/insert {collectionId, source, items:[{hash,text,index}]}`（**嵌入由服务端完成**，source=transformers 本地）
- `POST /api/vector/query {collectionId, searchText, topK, threshold, source}` → `{metadata:[], hashes:[]}`
- `POST /api/vector/list {collectionId, source}` → 已索引 hash 列表（去重用）

**实现**：
- 服务 `services/st/vectors.ts`：
  - `collectionId` = `stchat-<avatar>-<file>`（sanitize）；`hashMessage(text)` 32 位数值 hash（ST hashString 风格）
  - `indexMessages(session, messages)`：/list 去重 → 缺失的 /insert（metadata 存 `{hash, index}`）
  - `queryRelevant(session, searchText, topK)` → metadata 列表
- 设置：`extension_settings.vectors`（ST 同键）取 `enabled/top_k/template/depth`；App 开关 `stchat_vectors.enabled`
- 注入：`buildPrompt` 新增 `vectors?: {content, depth}` → @Depth system 块（默认 depth 4），
  内容模板 `相关的前文片段：\n{{text}}`
- 接线：`assemblePrompt` 查询（用最后一条用户消息文本）；`generateReply/continueReply` 完成后对新消息建索引
- UI：设置 → 通用 插件功能卡片加「向量记忆」子区（开关/topK/depth）

## 3. M-12 世界书递归 + timedEffects

**ST 事实**（world-info.js）：递归默认关；timedEffects 状态按会话持久化（chat_metadata）。

**实现**（worldinfo.ts）：
- `WiGlobals` 增加 `recursive: boolean`（默认 false，与 ST 默认一致）
- 递归：激活后把**新激活条目的 content** 并入扫描文本再匹配，最多 2 轮（防环：已激活不重复激活）
- timedEffects：`checkWorldInfo` 增加可选参数 `timed?: { map: Map<number, {sticky, cooldown}>; turn: number }`，
  返回 `activatedTimed: number[]`（本轮激活的 uid，供调用方更新状态）：
  - delay：`turn < entry.delay` → 不可激活（按消息进度）
  - sticky>0：强制激活并每轮递减
  - cooldown>0：跳过并每轮递减；条目激活时置 sticky/cooldown 计数
- 持久化：chat store 每会话把计数表存 `chat_metadata.timedEffects`（uid → {sticky, cooldown}），生成前加载、生成后写回
- 递归开关暴露：世界书页顶部「递归扫描」开关（写 WiGlobals localStorage）
