## 任务一：全量宏替换（与 ST 1.19 宏引擎对齐）

**现状**：App 仅支持 4 个宏（{{char}}/{{user}}/\<BOT\>/\<USER\>）+ 5 个简单宏（time/date/roll/random/pick）。
**ST 事实**（public/scripts/macros/definitions/*.js，约 55 个宏，7 类）：

### 方案
新建 `src/services/st/macros.ts` 宏引擎 v2：
- **词法**：扫描 `{{...}}`（大小写不敏感）；参数用 `::` 分隔（ST 惯例）；`{{//...}}` 注释删除
- **上下文对象 MacroContext**（调用方构造）：char/user/persona 描述、model、maxContext/maxResponse、最近消息（lastMessage/lastUserMessage/lastCharMessage）、swipeId、变量存储句柄
- **分类实现**：
  - core：space/newline/noop/trim/reverse/`//` 注释/maxPrompt/maxContext/maxResponse/roll（公式）/random/pick/outlet(空)/input(空)/banned(标记)/if 三参形式（块级 {{if}}…{{/if}} 暂缓，注明）
  - env：user/char/persona/charDescription/charPersonality/charScenario/charPrompt/charInstruction/charDepthPrompt/charCreatorNotes/charFirstMessage/charVersion/mesExamples(±Raw)/model/group 系列/isMobile
  - chat：lastMessage/lastMessageId/lastUserMessage/lastCharMessage/lastSwipeId/currentSwipeId
  - time：time/date/weekday/isotime/isodate/datetimeformat(idleDuration/timeDiff 置空)
  - variable：setvar/addvar/incvar/decvar/getvar/hasvar/deletevar/setvarkey/getvarkey + global 全套 —— **存储**：chat 级按会话键 localStorage（`app.chat.vars::*`），global 级 `app.vars.global`；与 ST chat_metadata.variables 不同步（注明，后续可加）
  - state/instruct：lastGenerationType/hasExtension/systemPrompt 等给安全默认值
- **接线**：prompt.ts 的 substituteMacros 变薄壳；buildPrompt 构造 MacroContext 传入；世界书/作者注释/消息内容同走此引擎

### 子任务
- [ ] 1.1 macros.ts 引擎（注册表 + 词法 + 各类 handler）
- [ ] 1.2 prompt.ts/chat.ts 接线（构造上下文、变量持久化）
- [ ] 1.3 离线自检脚本（按 ST 定义逐类断言，≥40 项）

## 任务二：全部生成源

**现状**：CC 24 源（vertexai/azure_openai/workers_ai/cometapi 禁用）+ 无 Text Completion。
**ST 事实**：CC 26 源；cometapi 在 ST 后端被硬禁用（throw，UI 注释）；vertexai 需 auth_mode/region（express 用 api_key_vertexai，full 用服务账号 secret `vertexai_service_account_json`）；azure 需 base_url/deployment/api_version + `api_key_azure_openai`；workers_ai 需 account_id + `api_key_workers_ai`。Text Completion 15 后端全部是**代理转发**（prompt 为单字符串，流式 `choices[].text`；ollama/llamacpp 有特殊包装）。

### 方案
- **2A CC 源补齐**：CHAT_SOURCES 补 vertexai（auth_mode/region/project 走 connConfig，密钥两把）、azure_openai（三件套 connConfig + 密钥）、workers_ai（account_id + 密钥）；cometapi 保持禁用（ST 后端硬禁用，写明原因）。api.ts buildBody 按源附加字段；设置页连接区按源渲染对应输入。
- **2B Text Completion**：新建 `services/st/textgen.ts`：
  - prompt 组装：系统提示 + 历史拼单字符串（instruct 关闭时的 ST 默认拼接级别，注明差异）
  - generateText：`/api/backends/text-completions/generate`，SSE 解析 `choices[].text` / llamacpp `content` / ollama 包装 / [DONE]
  - 后端配置（api_type/api_server/密钥）+ 采样参数白名单（generic/ooba/llamacpp/koboldcpp/aphrodite/vllm/ollama/togetherai/featherless/infermaticai/mancer/dreamgen/openrouter-text/huggingface）
  - 设置页：生成类型切换（Chat Completion / Text Completion）+ 后端选择 + server URL + 模型拉取（/v1/models）
- **2C 中断**：textgen 流同样接 AbortSignal（koboldcpp 另走 /api/extra/abort 上游，暂不接）

### 子任务
- [ ] 2.1 CC：vertexai/azure/workers_ai 三源的 buildBody + connConfig + 密钥 UI
- [ ] 2.2 textgen.ts：body 构建 + SSE 解析 + 中断
- [ ] 2.3 prompt 单字符串组装（textgen 模式）
- [ ] 2.4 设置页：生成类型/后端/连接配置 UI
- [ ] 2.5 自检（body 构造断言 + ST 在线时的连通冒烟）

## 任务三：插件（扩展）集成 · 一期

**ST 事实**：扩展编排逻辑几乎全在前端；服务器只提供端点（translate 8 家、classify、caption、speech/synthesize、quick-replies 存储、extension_settings 读写）。数据格式标准 = settings.json 的 `extension_settings.regex` / `quickReplyV2`。

### 方案（一期范围，数据格式与 ST 互通）
1. **Regex 引擎**（`services/st/regex.ts`）：RegexScript 全字段（scriptName/findRegex/replaceString/trimStrings/placement/disabled/markdownOnly/promptOnly/runOnEdit/minDepth/maxDepth/substituteRegex）；作用于 AI 输出显示、用户输入入库、提示词构建（isPrompt 通路）、推理块；来源=全局 `extension_settings.regex`（settings.json 读写）；角色级 SCOPED 后续
2. **快捷回复 QR**：套装 CRUD（存 `/api/quick-replies/save|delete`，格式对齐 QuickReplySet）+ 全局/角色绑定（`extension_settings.quickReplyV2`）+ 聊天输入区按钮条；message 直接触发发送（Slash 命令子集暂不支持，注明）
3. **消息翻译**：消息操作条「译」按钮 → `/api/translate/{provider}`，译文展示在气泡下方；设置（provider/target_language）写 `extension_settings.translate`
4. **TTS 朗读**：消息操作条「读」按钮 → `/api/speech/synthesize` → wav 播放（本地 transformers 引擎，首次下载模型慢，UI 提示）
5. **插件页**：现「插件」页增加"扩展"区块：discover 列表展示 + 上述功能设置入口
6. **明确不做（一期）**：第三方前端扩展动态加载（与 jQuery/DOM 深耦合）、STscript、memory/vectors 编排（独立排期）、自动执行触发器

- [ ] 3.3 翻译服务 + 消息操作条 + 设置
- [ ] 3.4 TTS 服务 + 朗读按钮
