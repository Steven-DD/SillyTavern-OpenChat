# B4 批次方案：群聊（M-8）（2026-09-28）

> 目标：与 ST 1.19 群聊数据完全互通 —— 同一个群在 App 与 ST 网页端打开看到同一群成员、同一份聊天记录。
> 数据全部落在 ST 目录（groups/*.json + group_chats/*.jsonl），App 不自建存储。

## ST 事实（源码实测）

- **端点**：`POST /api/groups/all`（列表）、`/api/groups/create`、`/api/groups/edit`、`/api/groups/delete`；
  群聊文件 `POST /api/chats/group/get {id}`（返回 jsonl 行数组）、`/save {id, chat}`（首行 header +
  消息行）、`/delete {id, chat_name}`、`/group/info {id}`（元数据）
- **群对象**：`{name, members: avatar[], avatar_url, allow_self_responses, activation_strategy,
  generation_mode, disabled_members, fav, chat_id, chats: [文件名...], auto_mode_delay}`
- **生成模式**（group-chats.js:129）：SWAP=0 每次回复轮换成员；APPEND=1 依次生成所有成员；
  APPEND_DISABLED=2 依次生成（含被禁用成员）
- **激活策略**：0 自然顺序（ST 内部打乱）、1 列表顺序、2 auto（talkativeness 掷骰：
  `talkativeness >= Math.random()` 者发言；无人命中则从 talkativeness>0 的成员里随机挑一个）
- **群聊行**：消息行带 `name`（发言成员名）；首行 header `user_name/character_name = 'unused'`

## 子任务

### 4.1 服务层 `services/st/groups.ts`
- `listGroups()/createGroup(model)/editGroup(patch)/deleteGroup(id, deleteChats)`
- `getGroupChat(id)/saveGroupChat(id, chat)/deleteGroupChat(id, name)/groupChatInfo(id)`
- 类型 `StGroup`（全字段透传）

### 4.2 编排纯函数 `services/st/group-orchestrate.ts`
- `pickSpeakers(group, members, lastSpeaker, turn) -> {avatar, forced?}[]`
  - APPEND/APPEND_DISABLED：按激活策略排序展开全部（natural=成员表顺序，list 同；禁用成员按模式过滤）
  - SWAP：单一发言人 = 成员表中 lastSpeaker 的下一个（跳过禁用）
  - auto（策略 2）：talkativeness 掷骰（≥random 激活），空集回退随机 1 人
  - 手动静音：disabled_members 过滤（APPEND_DISABLED 模式除外）
- 离线自检：三种模式顺序/轮换/掷骰回退/静音过滤

### 4.3 会话与生成编排（stores/chat.ts）
- 会话模型：sessionKey 前缀 `group::<groupId>::<chatId>`；群聊行 → DisplayMessage
  （`name` = 发言者名，头像按成员表映射）
- `send` 群聊分支：先把用户消息写入群聊文件；然后按 `pickSpeakers` 逐成员生成（APPEND 模式串行
  多气泡；SWAP/auto 单气泡）；每个成员的 prompt =
  `buildSystemParts(该成员卡) + 群聊指令块 + 历史`（成员按 name 标注，他人发言 role=assistant）
- 重新生成 = 重掷当前发言人（auto 模式）/ 上一发言人（SWAP）
- 落盘：`/api/chats/group/save`（复用行级格式：header + 消息行带 name）

### 4.4 UI
- 联系人页：群组列表区（群名 + 成员数）+ 新建群组对话框（群名 / 成员多选 / 激活策略 / 生成模式）
- 群组右键菜单：改名（编辑）/ 删除（含聊天记录确认）
- 聊天页：群聊气泡显示发言人名（头像用成员头像）；输入区照常；会话列表含群组会话
- ChatPanel 信息 Tab：群聊显示成员列表 + 生成模式切换（写 group.generation_mode）

### 4.5 验收
- 离线自检（4.2 断言 + 会话 key 解析）
- ST 在线冒烟：建群（含 2 个成员）→ App 发一条消息 → ST 网页端打开同一群验证消息与 swipes 兼容

## 明确不做（B4 范围外）
- 群聊内 @mentions 优先激活（v1 不做）
- auto_mode_delay 自动模式延时轮询（后台自动发言）
- 群头像上传（用默认头像）
- allow_self_responses（成员自问自答链）
